Build MovieHub from Scratch

A complete hands-on exercise to understand React + Express.js + MongoDB by building one Netflix-like movie application from an empty folder.

We will create the database, insert the supplied movie data, build an Express API, connect MongoDB, build the React interface, and finally connect the complete application.

Start here

1. What are we building?

MovieHub will look like a small Netflix-style application. Movies are not stored inside React. They live in MongoDB. Express provides URLs that React can call to get, create, update and delete movies.

MongoDB→Express API→React→Browser

MongoDB

Stores the movie documents permanently.

Express.js

Creates the backend server and API endpoints.

React

Creates the interactive user interface.

Mongoose

Helps the Express application work with MongoDB using schemas and models.

Important idea: Do not think of this as three separate applications. Think of it as one application with three layers that communicate with each other.

What you will understand by the end

  • What MongoDB, database, collection and document mean.
  • How to create a MongoDB database and insert data.
  • How Node.js and Express create a backend server.
  • What an API endpoint is and how HTTP methods work.
  • How Mongoose connects Express to MongoDB.
  • How React fetches data from an Express API.
  • How JSON travels from MongoDB → Express → React.
  • How to implement Create, Read, Update and Delete.

4. Part A — MongoDB from zero

4.1 Database, collection and document

MongoDB has a document-oriented structure:

Database→Collection→Document→Fields

For this application:

  • Database: moviehub
  • Collection: movies
  • One movie = one document
  • Fields: name, genre, releaseYear, rating, etc.

4.2 Create/select the MovieHub database

mongosh
show dbs
use moviehub
db
show collections
Why does use moviehub create the database?
It selects the database. MongoDB actually creates/persists the database when data is stored in it. Therefore, do not worry if show dbs does not immediately display an empty database.

4.6 Insert all 30 records using a seed script

Typing 30 documents manually is not practical. We will let Node.js read the data file and insert all records with Mongoose.

import mongoose from "mongoose";
import Movie from "./models/Movie.js";
import movies_data from "./moviehub_movies_data.js";

const MONGO_URI = "mongodb://127.0.0.1:27017/moviehub";

async function seedMovies() {
  try {
    await mongoose.connect(MONGO_URI);
    console.log("MongoDB connected");

    await Movie.deleteMany({});
    const movies = movies_data.map(({ id, ...movie }) => movie);
    await Movie.insertMany(movies);

    console.log(`${movies.length} movies inserted successfully`);
  } catch (error) {
    console.error("Seed failed:", error.message);
  } finally {
    await mongoose.disconnect();
  }
}

seedMovies();
Why remove id?
The supplied data has a numeric id. Mongoose/MongoDB will create its own unique _id. We keep the original movie information but let MongoDB manage its database identifier.

5.6 Create the Movie model

import mongoose from "mongoose";

const movieSchema = new mongoose.Schema({
  name: { type: String, required: true },
  genre: { type: String, required: true },
  releaseYear: { type: Number, required: true },
  rating: { type: String, required: true },
  duration: { type: String, required: true },
  director: { type: String, required: true },
  cast: { type: String, required: true },
  description: { type: String, required: true },
  bannerUrl: { type: String, required: true },
  trailer: { type: String, required: true }
});

const Movie = mongoose.model("Movie", movieSchema);

export default Movie;
Line by line:
new mongoose.Schema({...}) describes the shape of a movie. type: String means the field should contain text. type: Number means a number. required: true says the field must be supplied. mongoose.model("Movie", movieSchema) creates a model that Mongoose uses to work with the MongoDB collection.

5.7 Build the Express server

import express from "express";
import cors from "cors";
import mongoose from "mongoose";
import movieRoutes from "./routes/movieRoutes.js";

const app = express();
const PORT = 5000;
const MONGO_URI = "mongodb://127.0.0.1:27017/moviehub";

app.use(cors());
app.use(express.json());

app.get("/", (req, res) => {
  res.json({ message: "MovieHub API is running" });
});

app.use("/api/movies", movieRoutes);

mongoose
  .connect(MONGO_URI)
  .then(() => {
    console.log("MongoDB connected");
    app.listen(PORT, () => {
      console.log(`Server running at http://localhost:${PORT}`);
    });
  })
  .catch((error) => {
    console.error("MongoDB connection failed:", error.message);
  });
Important lines:
express() creates the application. app.use(cors()) enables cross-origin requests. app.use(express.json()) tells Express to understand JSON request bodies. mongoose.connect() connects to MongoDB. app.listen() starts the web server.

6. Part C — Build the REST API

An API is a set of URLs that another program can call. We will use HTTP methods to express the action.

MethodURLPurpose
GET/api/moviesRead all movies
GET/api/movies/:idRead one movie
POST/api/moviesCreate a movie
PUT/api/movies/:idUpdate a movie
DELETE/api/movies/:idDelete a movie

6.1 Create the routes

import express from "express";
import Movie from "../models/Movie.js";

const router = express.Router();

// GET /api/movies
router.get("/", async (req, res) => {
  try {
    const movies = await Movie.find().sort({ releaseYear: -1 });
    res.json(movies);
  } catch (error) {
    res.status(500).json({ message: error.message });
  }
});

// GET /api/movies/:id
router.get("/:id", async (req, res) => {
  try {
    const movie = await Movie.findById(req.params.id);
    if (!movie) return res.status(404).json({ message: "Movie not found" });
    res.json(movie);
  } catch (error) {
    res.status(400).json({ message: "Invalid movie id" });
  }
});

// POST /api/movies
router.post("/", async (req, res) => {
  try {
    const movie = await Movie.create(req.body);
    res.status(201).json(movie);
  } catch (error) {
    res.status(400).json({ message: error.message });
  }
});

// PUT /api/movies/:id
router.put("/:id", async (req, res) => {
  try {
    const movie = await Movie.findByIdAndUpdate(
      req.params.id,
      req.body,
      { new: true, runValidators: true }
    );
    if (!movie) return res.status(404).json({ message: "Movie not found" });
    res.json(movie);
  } catch (error) {
    res.status(400).json({ message: error.message });
  }
});

// DELETE /api/movies/:id
router.delete("/:id", async (req, res) => {
  try {
    const movie = await Movie.findByIdAndDelete(req.params.id);
    if (!movie) return res.status(404).json({ message: "Movie not found" });
    res.json({ message: "Movie deleted successfully" });
  } catch (error) {
    res.status(400).json({ message: "Invalid movie id" });
  }
});

export default router;
Understand req and res: req contains information sent by the client, such as URL parameters and JSON body. res is how the server sends a response back. async/await is used because database operations take time.

8.4 App.jsx — connect React to Express

import { useEffect, useState } from "react";
import MovieCard from "./components/MovieCard";
import MovieForm from "./components/MovieForm";
import "./App.css";

const API_URL = "http://localhost:5000/api/movies";

function App() {
  const [movies, setMovies] = useState([]);
  const [search, setSearch] = useState("");
  const [selectedMovie, setSelectedMovie] = useState(null);
  const [showForm, setShowForm] = useState(false);
  const [editingMovie, setEditingMovie] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  async function loadMovies() {
    try {
      setLoading(true);
      const response = await fetch(API_URL);
      if (!response.ok) throw new Error("Could not load movies");
      const data = await response.json();
      setMovies(data);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }

  useEffect(() => {
    loadMovies();
  }, []);

  const filteredMovies = movies.filter((movie) =>
    movie.name.toLowerCase().includes(search.toLowerCase()) ||
    movie.genre.toLowerCase().includes(search.toLowerCase()) ||
    movie.director.toLowerCase().includes(search.toLowerCase())
  );

  async function deleteMovie(id) {
    const ok = window.confirm("Delete this movie?");
    if (!ok) return;

    const response = await fetch(`${API_URL}/${id}`, { method: "DELETE" });
    if (response.ok) {
      setSelectedMovie(null);
      loadMovies();
    }
  }

  function startEdit(movie) {
    setEditingMovie(movie);
    setShowForm(true);
    setSelectedMovie(null);
  }

  return (
    <div className="app">
      <header className="navbar">
        <h1>MovieHub</h1>
        <div className="nav-actions">
          <input
            value={search}
            onChange={(e) => setSearch(e.target.value)}
            placeholder="Search movies..."
          />
          <button onClick={() => { setEditingMovie(null); setShowForm(true); }}>
            + Add Movie
          </button>
        </div>
      </header>

      <main>
        <section className="hero">
          <div>
            <p className="eyebrow">REACT + EXPRESS + MONGODB</p>
            <h2>Unlimited movies, built from scratch.</h2>
            <p>MovieHub reads movie data from MongoDB through an Express API.</p>
          </div>
        </section>

        {error && <p className="error">{error}</p>}
        {loading ? <p className="status">Loading movies...</p> : null}

        <section className="movie-grid">
          {filteredMovies.map((movie) => (
            <MovieCard
              key={movie._id}
              movie={movie}
              onClick={() => setSelectedMovie(movie)}
            />
          ))}
        </section>
      </main>

      {selectedMovie && (
        <div className="modal-backdrop" onClick={() => setSelectedMovie(null)}>
          <div className="modal" onClick={(e) => e.stopPropagation()}>
            <img src={selectedMovie.bannerUrl} alt={selectedMovie.name} />
            <h2>{selectedMovie.name}</h2>
            <p>{selectedMovie.description}</p>
            <p><b>Genre:</b> {selectedMovie.genre}</p>
            <p><b>Director:</b> {selectedMovie.director}</p>
            <p><b>Cast:</b> {selectedMovie.cast}</p>
            <div className="modal-actions">
              <button onClick={() => startEdit(selectedMovie)}>Edit</button>
              <button className="danger" onClick={() => deleteMovie(selectedMovie._id)}>Delete</button>
              <button onClick={() => setSelectedMovie(null)}>Close</button>
            </div>
            <iframe
              title={`${selectedMovie.name} trailer`}
              src={selectedMovie.trailer}
              allowFullScreen
            />
          </div>
        </div>
      )}

      {showForm && (
        <MovieForm
          movie={editingMovie}
          onClose={() => setShowForm(false)}
          onSaved={() => { setShowForm(false); loadMovies(); }}
        />
      )}
    </div>
  );
}

export default App;
Understand the most important part:
fetch(API_URL) sends an HTTP request to Express. response.json() converts the JSON response into JavaScript data. setMovies(data) puts that data into React state. React then re-renders the movie cards.

8.6 Add the CRUD form

import { useEffect, useState } from "react";

const API_URL = "http://localhost:5000/api/movies";

const emptyMovie = {
  name: "",
  genre: "",
  releaseYear: "",
  rating: "",
  duration: "",
  director: "",
  cast: "",
  description: "",
  bannerUrl: "",
  trailer: ""
};

function MovieForm({ movie, onClose, onSaved }) {
  const [form, setForm] = useState(emptyMovie);

  useEffect(() => {
    if (movie) {
      setForm({ ...movie });
    } else {
      setForm(emptyMovie);
    }
  }, [movie]);

  function handleChange(e) {
    const { name, value } = e.target;
    setForm((oldForm) => ({ ...oldForm, [name]: value }));
  }

  async function handleSubmit(e) {
    e.preventDefault();

    const isEditing = Boolean(movie);
    const url = isEditing ? `${API_URL}/${movie._id}` : API_URL;
    const method = isEditing ? "PUT" : "POST";

    const response = await fetch(url, {
      method,
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        ...form,
        releaseYear: Number(form.releaseYear)
      })
    });

    if (response.ok) {
      onSaved();
    } else {
      const data = await response.json();
      alert(data.message || "Could not save movie");
    }
  }

  return (
    <div className="modal-backdrop">
      <form className="form-modal" onSubmit={handleSubmit}>
        <h2>{movie ? "Edit Movie" : "Add Movie"}</h2>

        {Object.keys(emptyMovie).map((field) => (
          <input
            key={field}
            name={field}
            value={form[field]}
            onChange={handleChange}
            placeholder={field}
            required
          />
        ))}

        <textarea
          name="description"
          value={form.description}
          onChange={handleChange}
          placeholder="description"
          required
        />

        <div className="modal-actions">
          <button type="submit">Save</button>
          <button type="button" onClick={onClose}>Cancel</button>
        </div>
      </form>
    </div>
  );
}

export default MovieForm;

9. Part F — Understand the complete data flow

1. User opens React in browser.
2. App.jsx runs.
3. useEffect() calls loadMovies().
4. fetch() sends GET http://localhost:5000/api/movies.
5. Express receives the request.
6. movieRoutes.js matches GET /.
7. Movie.find() asks MongoDB for documents.
8. MongoDB returns movie documents.
9. Mongoose gives the result to Express.
10. Express sends JSON to React.
11. React stores JSON in movies state.
12. movies.map() creates MovieCard components.
13. Browser displays the Netflix-like grid.
This is the most important mental model: React does not directly talk to MongoDB. React talks to Express. Express talks to MongoDB.

Why does search happen in React here?

For a small dataset it is easy to load the movies once and filter them in the browser. Later, when the dataset becomes large, you can move search to Express and MongoDB using query parameters.

Next-level idea: Build GET /api/movies?search=inception and let Express perform the search. Then React does not need to download every movie.
